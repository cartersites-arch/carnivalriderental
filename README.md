# Carnival Rental Master

**Purpose:** one place holding everything built so far for the managed carnival ride rental marketplace, so it can be
verified before anything else is built. **This branch is an archive for review. It is not an app and cannot be built
or deployed** (there is no `package.json` at the root, on purpose).

Start with **[INVENTORY.md](INVENTORY.md)**.

| Folder | What it is |
|---|---|
| `sources/session-nice-bohr-wm2cp4/` | The "Carnival ride rental marketplace" Claude Code session's work, verbatim (branch `claude/nice-bohr-wm2cp4`, commit `52a72cb`). |
| `sources/session-lucid-goodall-d95lps/` | The "Sharetribe marketplace templates" session's carnival build, verbatim, as it was before it was removed (branch `claude/lucid-goodall-d95lps`, commit `cc081e0`). Built before verification against Sharetribe — kept only for comparison. |
| `sources/magic-patterns/` | Index of both Magic Patterns designs (the exports themselves are inside each session folder). |
| `reference/` | Facts verified from the Sharetribe Web Template source (v12.3.0) and the live Sharetribe docs, used to check both builds. |

Nothing in this branch contains credentials or customer/operator personal data (scanned before committing; see INVENTORY §2).
